**Thremark**:

A personal AI that lives in your pocket — it remembers things about you across conversations, so you don't have to repeat yourself.

Three tabs:

- **Marks** — your memory. Facts, preferences, notes you want it to retain.
- **Chat** — where you talk to it. It can search the web, create files, generate images, read documents, do calculations, set reminders.
- **Settings** — quality mode (Fast / Smart / Creative), GitHub sync, account stuff.
